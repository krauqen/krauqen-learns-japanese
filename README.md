# Krauqen Learns Japanese

This repo is a practical system for learning Japanese with a concrete first goal:

> Play Animal Crossing: New Horizons in Japanese comfortably.

The goal is not abstract fluency first. The first target is game fluency: reading enough Japanese to navigate menus, understand daily island routines, follow villager intent, and keep playing without every line becoming a full stop.

## Current Strategy

- Plan the first 2 months in detail because ACL recovery creates a specific homebound window.
- Keep the 6-12 month roadmap lightweight so it can adapt after real data from study and gameplay.
- Use Animal Crossing early as both motivation and training ground.
- Track outcomes with real-world weekly checkpoints, not only textbook progress.

## Daily Operating Principle

Each day has three possible versions:

- Minimum: keep the chain alive on low-energy recovery days.
- Normal: the default plan.
- Stretch: extra work only when energy is genuinely available.

The plan succeeds if Japanese stays present, useful, and recoverable after missed or hard days.

## Daily Coaching

Ask Codex:

```text
Use $daily-japanese-coach to walk me through today's Japanese study session and update the repo afterward.
```

The skill should help choose a minimum, normal, or stretch session based on time and recovery energy, then write the actual evidence back into the Markdown logs when the session is done.
