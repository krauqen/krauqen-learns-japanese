## Mark Encountered

| Mark | Reading | Seen in | Note |
| --- | --- | --- | --- |
| ー | long vowel | セーブ | Holds the previous vowel sound longer: see-bu. |
| ゛ | dakuten | が, ざ, だ, ば rows, で | Voices the base kana: ka->ga, sa->za, ta->da, ha->ba; て->で. |
| ゜ | handakuten | ぱ row | Turns the ha row into p sounds: pa/pi/pu/pe/po. |
| っ | small tsu | かっこいい | Doubles the following consonant sound: kak-koii. |
| ゃ | small ya | おちゃ, いしゃ | Combines with the previous sound: cha, sha. |

## Current Grammar Anchors

```text
これ = this
は = topic marker, pronounced wa in これは
です = desu = is / am / are
これはさかなです = kore wa sakana desu = This is a fish.
これはたぬきです = kore wa tanuki desu = This is a tanuki.
```
